# Agent Rules for Retronote Message Creation

When assisting users with generating, drafting, or creating messages in Retronote:

1. **Ask for Template & Requirements First**:
   - Always ask the user which template format they wish to create (e.g. `Apology`, `Birthday Surprise`, `Love Letter`, `Letter for Mom`, `Be My Valentine`, `Wedding Invitation`, `Surprise Reveal Box`, or `A Rose for Someone Special`).
   - Specify the recommended number of photos and photo types needed for that specific template (e.g., 2–4 memory photos for Apology, 1–3 celebration photos for Birthday).

2. **Inquire About Essential Details**:
   - Ask for the recipient's name or nickname.
   - Ask for key template details (e.g., occasion/milestone date, promises/secret hints, inside jokes, or specific wedding/event schedule).

3. **Draft & Customize**:
   - Offer customized prompt ideas or draft text matching the requested template's tone and animation flow.
